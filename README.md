# Sewer Crown (Sewerage_game)

University 3D game in Unity 6 (URP): cartoon / Y2K characters descend a sewer of 3 ring tunnels to grab the crown in the arena at the bottom.

- Random character with its own ability (dash, invisibility, flash, ground slam…)
- Bosses in guard rooms open the hatches to the next ring
- Procedural level (fans, grates, split paths, climb walls, wall breaches), toon shader with parallax bricks
- Procedural animation: run, jump, climb, 3-hit bat combo

**Unity:** 6000.0.84f1 · open the project folder and the `Sewer` scene, press Play.

Controls: WASD move, Space jump / climb, Shift sprint, LMB attack, E ability, Esc pause.
